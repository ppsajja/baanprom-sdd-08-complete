## สภาพแวดล้อม

เครื่องทดสอบของผู้ว่าจ้าง CPU 2 ตัว PostgreSQL 16 หลังบ้าน `python -m app.ops.serve --workers 2` โหมด production ติดตั้งจาก export สะอาดของ commit ที่ส่งตรวจ (ไฟล์ที่ git ติดตามเท่านั้น) venv ใหม่
กุญแจสามบทบาทคนละค่า (OPS_TOKEN CALL_CENTER_TOKEN FINANCE_TOKEN) ข้อมูลทดสอบจาก backend/uat_seed.py (ลูกค้า 30 ช่าง 10 ข้อมูลสมมติ)
ระบบภายนอกเป็นตัวจำลอง ตั้งให้ไม่ตอบได้ทีละตัวด้วย FAKE_GATEWAY_MODE MOCK_MAP_MODE MOCK_LINE_MODE MOCK_SMS_MODE (มีเฉพาะเครื่องทดสอบ) ข้อความของตัวจำลองเขียนลงไฟล์กลาง MOCK_OUTBOX_PATH เพราะรันหลาย process
สคริปต์ที่รันทั้งชุด: tools/oat08.sh ของกลุ่ม (นอก repo) ส่วนที่เป็นการเรียก API อยู่ใน backend/oat_r2.py
