# ผล OAT R2 บ้านพร้อม

แผน: docs/acceptance/oat-plan-r2.md | ผลดิบ (คำสั่งและผลที่เครื่องพิมพ์): docs/acceptance/oat-raw-r2.txt
ทุกตัวเลขในไฟล์นี้มาจากการรันจริงบนเครื่องทดสอบ (CPU 2 ตัว PostgreSQL 16 ติดตั้งจาก export สะอาดของ commit ที่ส่งตรวจ หลังบ้าน 2 process โหมด production) ส่วนที่เป็นการตัดสินของ Ops lead เป็นเรื่องสมมติเพื่อการสอน
รอบที่ใช้ตัดสินคือรอบที่สามของสคริปต์ สองรอบก่อนหน้าสคริปต์ผิด (GAP-48 GAP-49 ใน specs/000-shared/gaps.md) ไม่ใช่ระบบผิด ผลของรอบที่ผิดไม่ได้ใช้
