# UC-01 ช่างเข้าสู่ระบบ (fully dressed)

ระบบ: บ้านพร้อม R2 | ผู้เขียน: กลุ่ม X | เวอร์ชัน: 1.0 (เข้า Baseline B6 ตาม CR-11) | ที่มา: EV-051 (SH-06), หน้าบทเรียน Operational Security ("ช่างใช้บัญชีที่บ้านพร้อมออกให้")
ชื่อใน use-cases.md รุ่น B1 คือ "ลงทะเบียนและยืนยันตัวตนช่าง" R2 ทำเฉพาะการเข้าสู่ระบบ การยืนยันตัวตนช่างทำนอกระบบโดย SH-06 (การเชื่อม Thai-ID เป็น Q-69)

| หัวข้อ | รายละเอียด |
|---|---|
| Primary actor | ช่าง |
| Secondary actors | Ops (ออกบัญชี) ระบบส่งข้อความ (IF-02) |
| Goal | ช่างเห็นและทำงานของตัวเองเท่านั้น (precondition ของ UC-09 และ UC-12) |
| Precondition | SH-06 ตรวจเอกสารตัวตนของช่างแล้ว และ Ops ออกบัญชีด้วยเบอร์ของช่าง (REQ-FN-060) |
| Postcondition (สำเร็จ) | ช่างมี session 12 ชั่วโมง เห็นเมนูงานของช่างเมนูเดียว |
| Postcondition (ล้มเหลว) | ไม่มี session ใหม่ |
| Trigger | ช่างเปิดแอปและเลือก "ช่าง" |

## Main success scenario

1. ช่างกรอกเบอร์โทรที่ลงทะเบียนไว้ และกดขอรหัส OTP
2. ระบบส่งรหัสผ่าน IF-02
3. ช่างกรอกรหัส
4. ระบบออก session 12 ชั่วโมง และแสดงรายการงานของช่างคนนี้ (UC-09)

## Alternative flows

- A1 ครบ 12 ชั่วโมง: ระบบขอให้เข้าสู่ระบบใหม่

## Exception flows

- E1 (ขั้น 1) เบอร์ไม่มีบัญชีช่าง: ระบบตอบเหมือนเบอร์ที่มีบัญชี แต่ไม่ส่งข้อความ รหัสใดก็ไม่ผ่าน (D-02-02)
- E2 (ขั้น 3) รหัสผิด หมดอายุ หรือขอถี่เกิน: เหมือน UC-02 E1 ถึง E3
