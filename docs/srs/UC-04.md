# UC-04 ช่างจัดตารางเวลาว่างและวันหยุด (fully dressed)

ระบบ: บ้านพร้อม R2 | ผู้เขียน: กลุ่ม X | เวอร์ชัน: 1.0 (เข้า Baseline B7 ตาม CR-14) | ที่มา: MD-UCD-01, AS-15, AS-17, EV-053 (SH-06)

| หัวข้อ | รายละเอียด |
|---|---|
| Primary actor | ช่าง |
| Secondary actors | ไม่มี |
| Goal | ลูกค้าเห็นและจองได้เฉพาะเวลาที่ช่างว่างจริง ช่างไม่ต้องโทรบอกหัวหน้าช่างเมื่อหยุด |
| Precondition | ช่างเข้าสู่ระบบแล้ว (UC-01) |
| Postcondition (สำเร็จ) | ช่วงเวลาที่เพิ่มเป็น "ว่าง" ช่วงที่ปิดหรือวันหยุดไม่ปรากฏในการค้นหา การจอง การจับคู่ช่างใหม่ และการเลื่อนนัด |
| Postcondition (ล้มเหลว) | ตารางไม่เปลี่ยน ระบบบอกเหตุ |
| Trigger | ช่างเปิดเมนู "ตารางเวลา" |

## Main success scenario

1. ช่างเปิดตารางของตัวเอง ระบบแสดง 14 วันข้างหน้า แต่ละช่วงบอกสถานะ ว่าง ถูกล็อก จองแล้ว หรือปิด
2. ช่างเลือกวันและเวลาเริ่ม แล้วกด "เพิ่มช่วงว่าง"
3. ระบบตรวจตาม BR-10 ข้อ 1 ถึง 4 แล้วบันทึกช่วงเป็น "ว่าง"
4. ลูกค้าที่ค้นหาช่างประเภทเดียวกันเห็นช่วงนั้น (UC-07 ขั้น 2)

## Alternative flows

- A1 (ขั้น 2) ช่างปิดช่วงที่ยังว่าง: ช่วงเป็น "ปิด" ลูกค้าไม่เห็น ช่างเพิ่มช่วงเดิมได้อีกครั้งเพื่อเปิดคืน (BR-10 ข้อ 4 และ 5)
- A2 (ขั้น 2) ช่างประกาศวันหยุดทั้งวัน: ช่วงที่ว่างของวันนั้นเป็น "ปิด" เพิ่มช่วงในวันนั้นไม่ได้ (BR-10 ข้อ 6)
- A3 (หลัง A2) ช่างยกเลิกวันหยุด: เฉพาะช่วงที่ปิดเพราะวันหยุดและยังไม่เริ่มกลับเป็น "ว่าง" (BR-10 ข้อ 8)

## Exception flows

- E1 (ขั้น 3) ช่วงไม่เริ่มตรงชั่วโมง อยู่นอก 08:00 ถึง 20:00 ใกล้เกิน 1 ชั่วโมง ไกลเกิน 30 วัน หรือซ้อนช่วงเดิม: ระบบปฏิเสธพร้อมเหตุ
- E2 (A1) ช่วงที่ลูกค้ากำลังล็อกหรือจองแล้ว: ปิดไม่ได้ ช่างต้องปฏิเสธงานผ่าน UC-12 ก่อน
- E3 (A2) วันที่มีงานจองแล้วหรือลูกค้ากำลังล็อก: ประกาศวันหยุดไม่ได้ ระบบบอกเลขงาน (BR-10 ข้อ 7)
- E4 ช่างคนอื่นหรือลูกค้าส่งคำขอแก้ตารางของช่างนี้: 403 และบันทึก (REQ-SEC-010)
