# UC-05 จับคู่ช่างใหม่เมื่อช่างปฏิเสธ (fully dressed)

ระบบ: บ้านพร้อม R2 | ผู้เขียน: กลุ่ม X | เวอร์ชัน: 1.0 (เข้า Baseline B6 ตาม CR-12) | ที่มา: UC-07 E3, MD-STM-01, BR-01 R4, REQ-003 (รหัสร่าง), EV-051
ความสัมพันธ์: extend UC-07 ที่ E3 (ช่างปฏิเสธงานหลังยืนยัน) เริ่มจาก UC-12 E1 หรือ E2

| หัวข้อ | รายละเอียด |
|---|---|
| Primary actor | ระบบ (เริ่มเอง) |
| Secondary actors | ลูกค้า ช่างใหม่ ระบบส่งข้อความ (IF-02) Payment Gateway (IF-01 เมื่อคืนเงิน) |
| Goal | ลูกค้ายังได้ช่างในเวลาเดิม โดยไม่ต้องโทร call center หรือจองใหม่ |
| Precondition | งานเป็น "กำลังหาช่างใหม่" |
| Postcondition (สำเร็จ) | งานเป็น "ยืนยันแล้ว" กับช่างใหม่ เวลาเดิม ช่วงเวลาของช่างใหม่ "จองแล้ว" ลูกค้าและช่างใหม่ได้รับแจ้งภายใน 60 วินาที |
| Postcondition (ล้มเหลว) | งานเป็น "ยกเลิก" คืนมัดจำเต็ม (BR-01 R4) ลูกค้าได้รับแจ้ง |
| Trigger | ช่างปฏิเสธหรือไม่ตอบ (UC-12 E1 E2) |

## Main success scenario

1. ระบบหาช่วงเวลา "ว่าง" ที่เริ่มเวลาเดียวกับนัดเดิม ของช่างที่ทักษะตรง อยู่ในระยะ 15 กม. และยังไม่เคยได้รับงานนี้ (BR-07 ข้อ 3)
2. ระบบเลือกช่างที่ใกล้ที่สุด จองช่วงเวลานั้น และเปลี่ยนงานเป็น "ยืนยันแล้ว"
3. ระบบมอบงานให้ช่างใหม่แบบช่างแทน (UC-12 เริ่มใหม่กับช่างคนนี้)
4. ระบบแจ้งลูกค้า (ชื่อช่างใหม่ และสิทธิ์ไม่รับช่างแทน) และแจ้งช่างใหม่

## Alternative flows

- A1 (ขั้น 1) ยังไม่มีช่าง: ระบบแจ้งลูกค้าว่ากำลังหาช่างใหม่ภายใน 2 ชั่วโมง แล้วลองขั้น 1 ทุก 1 นาที
- A2 (หลังขั้น 4) ลูกค้าไม่รับช่างแทน ก่อนช่างแทนออกเดินทาง: ยกเลิก คืนมัดจำเต็ม (BR-01 R4 BR-07 ข้อ 6)
- A3 (หลังขั้น 4) ช่างใหม่ปฏิเสธหรือไม่ตอบ: กลับขั้น 1 โดยไม่เสนอช่างที่เคยได้รับงานนี้

## Exception flows

- E1 (A1) ครบ 2 ชั่วโมงยังไม่มีช่าง หรือเหลือเวลาก่อนนัดน้อยกว่า 1 ชั่วโมง: ยกเลิก คืนมัดจำเต็มผ่าน IF-01 (BR-01 R4) gateway ปฏิเสธหรือไม่ตอบใช้ทางเดิมของ UC-08 E1 (REQ-IF-010)

## Business rules ที่อ้าง

BR-07 | BR-01 R4 | BR-02 | BR-03
