# UC-11 ลูกค้าให้คะแนนช่างหลังจบงาน (fully dressed)

ระบบ: บ้านพร้อม R2 | ผู้เขียน: กลุ่ม X | เวอร์ชัน: 1.0 (เข้า Baseline B7 ตาม CR-15) | ที่มา: MD-UCD-01, Q-20 (EV-051), EV-053 (SH-01 SH-05)

| หัวข้อ | รายละเอียด |
|---|---|
| Primary actor | ลูกค้า |
| Secondary actors | ระบบส่งข้อความ (IF-02) ผ่าน UC-10 |
| Goal | ลูกค้าคนต่อไปเห็นคุณภาพของช่างจากงานจริง โดยคะแนนไม่ถูกปลอมและไม่เปิดเผยข้อมูลส่วนบุคคล |
| Precondition | ลูกค้าเข้าสู่ระบบแล้ว (UC-02) และมีงานของตัวเองสถานะ "เสร็จสิ้น" ที่ช่างปิดไม่เกิน 14 วัน |
| Postcondition (สำเร็จ) | มีคะแนน 1 รายการต่องาน ค่าเฉลี่ยในผลค้นหาเปลี่ยนเมื่อมีคะแนนที่นับได้ตั้งแต่ 3 คะแนน |
| Postcondition (ล้มเหลว) | ไม่มีคะแนนใหม่ ระบบบอกเหตุ |
| Trigger | ลูกค้าเปิด "งานของฉัน" แล้วกด "ให้คะแนน" ใต้งานที่เสร็จสิ้น |

## Main success scenario

1. ลูกค้าเปิด "งานของฉัน" ระบบแสดงปุ่ม "ให้คะแนน" เฉพาะงานที่ให้ได้ตาม BR-11
2. ลูกค้าเลือก 1 ถึง 5 ดาว และพิมพ์ความเห็นสั้น (ไม่บังคับ)
3. ระบบปิดบังเบอร์ อีเมล เลขบัตรในความเห็น บันทึกคะแนน และตอบ "ขอบคุณสำหรับคะแนน"
4. ผลค้นหาช่าง (UC-07 ขั้น 2) แสดง "คะแนนเฉลี่ย X.X จาก 5 (N คะแนน)" ลำดับช่างไม่เปลี่ยน

## Alternative flows

- A1 (ขั้น 4) คะแนนที่นับได้น้อยกว่า 3: แสดง "ยังมีคะแนนไม่พอแสดงค่าเฉลี่ย"
- A2 (ขั้น 3) บัญชีลูกค้าใช้เบอร์เดียวกับบัญชีของช่างคนนั้น: บันทึกได้และตอบเหมือนกัน แต่ไม่นับในค่าเฉลี่ย (BR-11 ข้อ 5)

## Exception flows

- E1 งานยังไม่เสร็จสิ้น เกิน 14 วัน หรือให้แล้ว: ระบบปฏิเสธพร้อมเหตุ ไม่มีการแก้คะแนน
- E2 ลูกค้าคนอื่นหรือช่างส่งคะแนนของงานนี้: 403 และบันทึก (REQ-SEC-010)
- E3 ลูกค้าขอลบข้อมูล (REQ-PRV-010): ความเห็นถูกลบ ดาวคงไว้แบบไม่ระบุตัว
