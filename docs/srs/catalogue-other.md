## 3. รหัสร่างจากทะเบียนหลักฐาน

บทเรียน Elicitation ใช้รหัสร่างแบบไม่มีหมวด บทเรียน Taxonomy ให้ตั้งรหัสใหม่ตามหมวด และจดรหัสเดิมไว้ที่นี่

| รหัสร่าง | ความหมาย | ผล |
|---|---|---|
| REQ-001 | หน้าบทเรียนไม่ได้แสดงข้อความ (EV-002 อ้างถึง) | ยังไม่ตั้งรหัสใหม่ ต้องหาข้อความเดิม |
| REQ-003 | เมื่อช่างยกเลิกงานที่ยืนยันแล้ว แจ้งผู้ใช้และเสนอช่างทดแทน | ยังไม่ตั้งรหัสใหม่ เนื้อหาอยู่ใน UC-07 E3 และ UC-05 (R2) |
| REQ-012 | กันช่วงเวลาที่ช่างตอบรับแล้วไม่ให้ถูกจองซ้ำ | ตกหล่นตอนทำ catalogue รุ่นแรก ภายหลังโมเดลพบซ้ำเป็น REQ-FN-041 (CC-02) และ BR-02 |
| REQ-018 | ช่องทางติดต่อระหว่างลูกค้ากับช่าง | ตัดสินแล้วใน DR-01 ต้องเขียนข้อใหม่ในหมวด IF และ PRV ยังไม่ออกเลข |
| REQ-021 | แจ้งชื่อและทะเบียนรถช่างให้นิติบุคคลหมู่บ้านล่วงหน้า | ยังไม่ตั้งรหัสใหม่ รอคุยกับ SH-04 |
