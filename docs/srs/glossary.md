# Glossary v1.0 (เข้า Baseline B1)

ใช้คำในตารางนี้เท่านั้น ทั้งใน spec.md, .feature, โค้ด และหน้าจอ ถ้าต้องใช้คำใหม่ ให้เสนอเป็นคำถาม

| คำ (ไทย) | ชื่อในโค้ด | ความหมาย |
|---|---|---|
| ลูกค้า | Customer | ผู้ใช้ที่ลงทะเบียนแล้วและเป็นผู้จองงาน |
| ช่าง | Technician | ผู้ให้บริการซ่อมที่ผ่านการยืนยันตัวตน (UC-01) |
| งาน | Job | การจอง 1 รายการ ตั้งแต่สร้างจนปิด มีสถานะตาม MD-STM-01 |
| ช่วงเวลา | TimeSlot | ช่วงเวลาทำงานของช่าง 1 ช่วง สถานะ ว่าง / ล็อกชั่วคราว / จองแล้ว |
| มัดจำ | deposit | เงินที่ลูกค้าชำระตอนยืนยันจอง ปัดขึ้นหลักสิบ |
| การชำระ | Payment | รายการตัดมัดจำ 1 รายการ ผลเป็น สำเร็จ / ล้มเหลว / หมดเวลา |
| การคืนเงิน | Refund | รายการคืนมัดจำตาม BR-01 |
| ที่อยู่ให้บริการ | ServiceAddress | ที่อยู่ที่ช่างต้องไป ลูกค้าหนึ่งคนมีได้หลายที่ (AS-03) |
| ยืนยันแล้ว | confirmed | สถานะงานหลังชำระมัดจำสำเร็จ |
| รอชำระเงิน | pending_payment | สถานะงานตั้งแต่กดยืนยันจนชำระสำเร็จ |
| ยกเลิกอัตโนมัติ | auto_cancelled | สถานะงานเมื่อ E1 (ไม่ชำระใน 30 นาที หรือชำระไม่สำเร็จ) |
| กำลังหาช่างใหม่ | rematching | สถานะงานเมื่อ E3 ช่างปฏิเสธ |
| ช่างกำลังเดินทาง | en_route | ช่างกดออกเดินทาง |
| กำลังดำเนินงาน | in_progress | ช่างกด check-in ที่หน้างาน |
| เสร็จสิ้น | done | ช่างปิดงานแล้ว (CR-10 Q-31: ไม่มีขั้นลูกค้ายืนยัน ลูกค้าแจ้งว่างานยังไม่เรียบร้อยผ่าน call center ได้ภายใน 7 วัน) |
| ยกเลิก | cancelled | ลูกค้าหรือระบบยกเลิกตาม BR-01 |
| ล็อกช่วงเวลาชั่วคราว | hold | การกันช่วงเวลาไว้ระหว่าง UC-07 ขั้น 3 ถึง 5 (REQ-FN-041) |
| สอบถามสถานะ | status-inquiry | การถาม gateway ว่ารายการที่ค้างสำเร็จหรือไม่ ด้วย reference เดิม (REQ-IF-005) |

## คำที่เพิ่มหลัง CR-10 (EV-048)

| คำ | ภาษาอังกฤษในระบบ | ความหมาย |
|---|---|---|
| ราคาประเมิน | estimate_amount | ค่าบริการเบื้องต้นของประเภทงานตามตารางของ Finance ไม่รวมค่าอะไหล่ ช่างแจ้งราคาจริงก่อนเริ่มงาน (REQ-FN-057) |
| ค่าเดินทางเหมา | TRAVEL_FEE_BAHT | ยอดที่หักจากมัดจำให้ช่างเมื่อลูกค้ายกเลิกขณะช่างกำลังเดินทาง (BR-01 R3) |
| รายการคืนเงินที่ต้องติดตาม | refunds follow-up | รายการคืนเงินที่ gateway ปฏิเสธ (declined) หรือไม่ทราบผล (unknown) ที่ Finance ต้องปิดภายใน 1 วันทำการ |

## คำที่เพิ่มใน R2 ส่วน A (CR-11, CR-12, CR-08, CR-13 EV-051)

| คำ | ภาษาอังกฤษในระบบ | ความหมาย |
|---|---|---|
| เข้าสู่ระบบ | login, session | ยืนยันตัวด้วยเบอร์โทรและรหัส OTP แล้วได้ session ลูกค้า 30 วัน ช่าง 12 ชั่วโมง (BR-09) |
| รหัส OTP | otp, OtpChallenge | รหัสตัวเลข 6 หลักที่ระบบส่งทางข้อความ ใช้ได้ 5 นาที ลองผิดได้ 5 ครั้ง |
| บัญชี | Account | ตัวตนของลูกค้าหรือช่าง 1 คนต่อ 1 เบอร์ต่อบทบาท บัญชีช่างออกโดยบ้านพร้อม |
| ออกจากระบบ | logout | ยกเลิก session ปัจจุบัน ใช้ต่อไม่ได้ทันที |
| รับงาน | accept, response = accepted | ช่างยืนยันว่าจะไปทำงานที่มอบให้ ไม่เปลี่ยนสถานะงาน (MD-STM-04) |
| ปฏิเสธงาน | reject, response = rejected | ช่างไม่รับงาน งานไป "กำลังหาช่างใหม่" |
| ไม่ตอบ | response = no_response | ช่างไม่รับและไม่ปฏิเสธภายใน 30 นาที ถือว่าปฏิเสธ |
| ช่างแทน | substitute, via_rematch | ช่างที่ระบบจับคู่ให้แทนช่างที่ปฏิเสธ (UC-05) เวลานัดเดิม |
| ไม่รับช่างแทน | decline-substitute | ลูกค้ายกเลิกงานที่ได้ช่างแทน คืนมัดจำเต็ม (BR-01 R4) |
| ช่างที่เคยใช้ | past technicians | ช่างของงานที่เสร็จสิ้นของลูกค้าใน 12 เดือน ไม่เกิน 3 คน (BR-08) |
| งานของฉัน | my jobs | รายการงานของลูกค้าที่เข้าสู่ระบบ (UI-02-03) |
