# CR-19 ผู้ช่วย: ระยะเวลาเงินคืนขึ้นกับธนาคาร (Q-65) ชั้นที่ 3 ของการรับโมเดล ชุดลับของ eval set และ LLM ตัวจริงที่ปิดไว้ (R2 ส่วน B)

สถานะ: Approved (SH-01, SH-05, หัวหน้า call center, Ops lead ในประชุมงวด 2 ของ R2 EV-053 วันที่ 10 ธ.ค. 2569) | สถานะเดิมตอนเสนอ: Proposed (3 ธ.ค. 2569)
ประเภท: minor (REQ ใหม่ 2 ข้อ AC ใหม่ 3 ข้อ eval set รุ่นใหม่ ไม่เปลี่ยน BR-06 และขอบเขตของผู้ช่วย)
ผู้ขอ: หัวหน้า call center (Q-65 ค้างจาก CR-10) และ TOR ของ R2 ภาคผนวก ค (eval set 200 ข้อ ผู้รับจ้างเห็น 150 ข้อ ชุดลับ 50 ข้อ)
ข้อมูลทั้งหมดในบันทึกนี้เป็นข้อมูลสมมติเพื่อการสอน บันทึกประชุมเต็มอยู่ใน specs/000-shared/changes/CR-18.md ส่วน "บันทึกประชุมงวด 2 ของ R2"

## ทำไมต้องเปลี่ยน

1. Q-65 ค้างตั้งแต่ CR-10: ลูกค้าถาม "เงินคืนเข้ากี่วัน" ผู้ช่วยตอบแค่ "ยังไม่มีข้อมูล" ลูกค้าจึงโทรถาม call center ต่อ หัวหน้า call center ขอให้บอกว่าขึ้นกับธนาคารผู้ออกบัตร เหมือนหน้าผลการยกเลิก (Q-35)
2. TOR ของ R2 แบ่ง eval set เป็นชุดที่ผู้รับจ้างเห็น 150 ข้อ และชุดลับ 50 ข้อของผู้ว่าจ้าง ไฟล์ของ eval ยังไม่มีการแบ่ง
3. ตัวเลขการรับของ CR-09 วัดกับ MockLLM รุ่นเดียว ถ้าระบบจริงเปลี่ยนโมเดล (หรือผู้ให้บริการเปลี่ยนรุ่นเอง) ผลที่ผ่านไม่มีความหมาย ต้องมีชั้นที่ 3 ของการรับ: ผู้ช่วยทำงานเฉพาะรุ่นโมเดลที่ผ่าน eval ทั้งชุดแล้ว
4. TOR ข้อ 2 ให้ทุกระบบภายนอกมีตัวจริงที่สลับได้ด้วยค่าตั้ง (REQ-IF-012 ของ CR-18) รวม LLM (IF-05)
