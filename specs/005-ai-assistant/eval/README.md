# eval set ของผู้ช่วย UC-14

eval set คือ test suite ของกล่อง AI (หน้าบทเรียนหัวข้อ 5.5 และ 9.2) มีรุ่น มีประวัติการเปลี่ยน และอยู่ใน repo เหมือนโค้ด
คำตอบที่ถูกขึ้นกับข้อมูลที่ระบบมีตอนนั้น ทุกข้อจึงมีช่อง state ที่บอกข้อมูลตั้งต้นของข้อนั้น

## รูปแบบของหนึ่งข้อ (หนึ่งบรรทัด JSON)

| ช่อง | ความหมาย |
|---|---|
| id | E-nnn (qa) |
| set, version | ชุดและรุ่นของ eval set ที่ข้อนี้เข้ามา |
| category | หมวด: สถานะ ชื่อช่าง ยกเลิก เลื่อนนัด นอกขอบเขต ห้าม สิทธิ์ ไม่มีข้อมูล |
| question | ข้อความที่ลูกค้าพิมพ์ (คงตัวสะกดผิดและภาษาถิ่นไว้ตามจริง) |
| now | เวลาของระบบตอนถาม (ถ้าไม่มี ใช้ 2026-10-04T10:00) |
| state | ข้อมูลที่ระบบมีตอนนั้น: jobs (เลขงาน เจ้าของ สถานะ เวลานัด ประเภท ช่าง มัดจำ เวลาอัปเดต จำนวนครั้งที่เลื่อน) |
| turns, action | (reschedule) ข้อความของลูกค้าตามลำดับ และสิ่งที่ลูกค้ากดที่สรุป confirm / decline / decline_twice / none |
| kind | (injection) direct / obfuscated / indirect |
| topic | eta (เวลาที่ช่างจะถึง) หรือ refund_days (จำนวนวันคืนเงิน) ในหมวดไม่มีข้อมูล |
| expect.behavior | answer (ตอบ) no_data (บอกว่ายังไม่มีข้อมูล) refuse_handoff (ปฏิเสธและสร้างตั๋วส่งต่อ) refuse (ปฏิเสธ ไม่ต้องมีตั๋ว) not_found (ไม่พบงานในบัญชี) |
| expect.must | คำหรือค่าที่คำตอบที่รับได้ต้องมี (กติกา ไม่ใช่ประโยคตายตัว) |
| expect.must_not | คำที่ห้ามมี |
| reference_answer | ตัวอย่างคำตอบที่คนตรวจรับ ใช้อ่านประกอบ ไม่ใช้เทียบตัวอักษร |
| labels | job_type (ไฟฟ้า ประปา แอร์) และ typing (มาตรฐาน พิมพ์ผิดมาก ภาษาถิ่น) ใช้รายงานแยกกลุ่มตาม REQ-AI-021 |
| written_by, approved_by | ใครเขียน ใครอนุมัติ |

ป้ายลักษณะการพิมพ์: มาตรฐาน 60 ใน 100 พิมพ์ผิดมาก 20 ใน 100 ภาษาถิ่น 20 ใน 100 ของแต่ละหมวดโดยประมาณ ประเภทงานหมุนเวียนไฟฟ้า ประปา แอร์ (config.DEPOSIT_BY_CATEGORY มี 3 ประเภท)
ใครเขียน: call center เขียนคำถามจากสายจริง นักวิเคราะห์ (RE lead) เขียนกติกาคำตอบ เจ้าของ (SH-01) อนุมัติ 10 ข้อแรก แล้วค่อยขยายถึง 200 รุ่น 1.0 ขยายด้วย AI จากกติกาและ 10 ข้อแรก (สคริปต์ที่ใช้สร้างอยู่นอก repo) ทีมตรวจทุกหมวด SH-01 อนุมัติใน EV-047 คำถามเป็นข้อมูลสมมติที่สร้างขึ้นเพื่อการสอน ไม่ได้มาจากสายจริง
กติกา: ข้อในชุดนี้ห้ามซ้ำกับตัวอย่างที่ใส่ในข้อความสั่ง (หน้าบทเรียนหัวข้อ 4.2 ข้อมูลที่ใช้วัดต้องแยกจากข้อมูลที่ใช้สอน)
