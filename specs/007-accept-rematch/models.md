## MD-SEQ-05-01 ช่างปฏิเสธและระบบจับคู่ช่างใหม่ (UC-12 E1 ต่อ UC-05)

```mermaid
sequenceDiagram
  participant T as ช่างเดิม
  participant S as ระบบบ้านพร้อม
  participant N as ระบบส่งข้อความ (IF-02)
  participant T2 as ช่างใหม่
  participant C as ลูกค้า
  T->>S: POST /jobs/{id}/reject (token ของช่าง)
  S->>S: ตรวจสิทธิ์ (REQ-SEC-010) และ BR-07 ข้อ 1
  S->>S: การตอบ = ปฏิเสธ งาน = กำลังหาช่างใหม่ ช่วงเวลาเดิม = ว่าง
  S-)N: แจ้งช่างเดิมว่าส่งต่อแล้ว
  alt มีช่างตาม BR-07 ข้อ 3 และเหลือเวลาตามข้อ 4
    S->>S: ช่วงเวลาใหม่ = จองแล้ว งาน = ยืนยันแล้ว มอบงานแบบช่างแทน
    S-)N: แจ้งลูกค้า (ชื่อช่างใหม่) และช่างใหม่ (ตอบภายใน 30 นาที)
  else ยังไม่มี

    loop ทุก 1 นาที (งานเบื้องหลัง REQ-OP-008)
      S->>S: ลอง BR-07 ข้อ 3 อีกครั้ง
    end
    S->>S: ครบ 2 ชั่วโมง หรือเข้าข้อ 4 ยกเลิกตาม BR-01 R4 คืนเต็มผ่าน IF-01
  end
  C->>S: GET /me/jobs ถ้าได้ช่างแทนและไม่ต้องการ POST /jobs/{id}/decline-substitute (R4)
```
